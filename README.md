# Tetris Game – Python in the Browser (PyScript)
▶️ [Play Here](https://arassp.github.io/Tetris/) 

An old project for a classic Tetris game written in Python that runs in the browser using PyScript and now hosted with GitHub Pages. The goal of this project was to demonstrate Python game logic, keyboard input and canvas drawing, as well as browser integration using PyScript which was added later.
Feel free to play around with it and enjoy 

---

## Controls
- **Left Arrow** – Move piece left  
- **Right Arrow** – Move piece right  
- **Down Arrow** – Drop faster  
- **Up Arrow** – Rotate piece  
- **Space** – Hard drop  
- **P** – Pause / Resume
